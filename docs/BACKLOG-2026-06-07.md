### 2. RBAC Middleware Integration (Phase 5 of plan)

**File to update**: `internal/middleware/` — add RBAC check after JWT validation.

The `Manager.Authorize(subjectID, directPolicies, resource, capability)` method is already designed for this.
After JWT validation extracts `subjectID` and `directPolicies`, call `Authorize` before forwarding to the handler.

Wire it to protect write operations on `/kv/*`, `/services/*`, `/acl/*`.

**Est**: 3 hours

### 3. Wire RBAC into `main.go`

`cmd/konsul/main.go` does not reference `internal/rbac` at all.

When `cfg.RBAC.Enabled`:
1. Choose backend: `BadgerRoleStore`/`BadgerAssignmentStore` if persistence is on, else memory variants.
2. Construct `rbac.NewManager(roles, assignments, cfg.RBAC.CacheTTL, cfg.RBAC.ExpirationCheckInterval, log)`.
3. Register RBAC handler routes.
4. Pass `Manager` to RBAC middleware.
5. Defer `manager.Close()` in shutdown.

**Est**: 2 hours

Add hit/miss counters in `GetEffectivePolicies` and update the ratio periodically or on each access:
