## P1 — Текущий спринт (2026-06-03 → 2026-06-10)

### 1. BACK-006: Enhanced RBAC System

**Priority**: P1 | **Effort**: 21 SP | **ADR**: ADR-0025

Расширить существующую ACL систему до полноценного RBAC с ролями, группами и иерархией.
Это разблокирует BACK-007 (LDAP), BACK-013 (Namespaces) и secret management.

**Что строить (из ADR-0025)**:
- `Role` — именованный набор политик
- `RoleAssignment` — привязка token/user → role
- `GroupRoleMapping` — group → role
- Иерархия ролей (max 5 уровней), кэш (5m TTL, >95% hit rate)
- CRUD API: `GET/POST/PUT/DELETE /acl/roles/:name`
- Assignment API: `PUT/DELETE /acl/roles/:name/assign`
- Prometheus метрики для role operations
- Хранилище: BadgerDB (extends existing persistence)
- Auth latency p99 <2ms

**Acceptance Criteria (из BACKLOG)**:
- [ ] Role, RoleAssignment, GroupRoleMapping data model
- [ ] RoleStore (BadgerDB)
- [ ] Role hierarchy resolution (max 5 levels)
- [ ] Effective permissions calculation
- [ ] Cache for role lookups
- [ ] Role management API endpoints
- [ ] RBAC middleware (extends ACL middleware)
- [ ] Unit + integration tests
- [ ] Docs

**Est**: 2026-06-03 → 2026-06-24
